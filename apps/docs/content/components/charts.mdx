# Charts

Line, bar, area and donut charts on [recharts](https://recharts.org), coloured from the chart tokens.

Charts have their own entry, so apps without charts don't install recharts:

```sh
pnpm add recharts
```

```tsx
import { Chart } from "@kifiya/ui/chart";
```

Every chart needs a `label`: screen readers read it in place of the drawing.

# Data table

`PortalTable` pages on the server: it never loads a full list.

## PortalTable — server-side paging

The app fetches one page and passes it in with `pagination` and `onPaginationChange`; the table shows only those rows. Columns are typed (`text`, `chip`, `avatar`, `date`, `actions`, …).

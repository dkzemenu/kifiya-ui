# Overlays

Everything that opens above the page. All of them close on Escape and return focus to the control that opened them.

Floating content anchored to a trigger.

## Tooltip

Needs a `TooltipProvider` above it, mounted once near the app root.

## DropdownMenu

Items, checkbox items, radio groups and sub-menus.

<Example name="overlays/DropdownMenuStory" />

## Sheet

The primitive side panel. `SheetContent` renders `SheetPortal` and `SheetOverlay` for you. For forms, use `PortalDrawer`.

<Example name="overlays/SheetStory" />

## PortalDrawer

The standard side drawer for create and edit forms: title, optional icon, body and a sticky footer. Focus returns to the opener on close.

<Example name="overlays/Drawer" />

## PortalConfirmDialog

Asks before a consequential action. `confirmVariant` sets the tone; `isLoading` and `error` cover the request in flight.

<Example name="overlays/ConfirmDialog" />

## Toaster

Mount `<Toaster />` once, then call `toast` (re-exported from the kit).

<Example name="overlays/Toasts" />

## Dialog

A general modal for forms and details. For a yes/no question use `PortalConfirmDialog`; for a side panel, `PortalDrawer`. `size` sets the maximum width (`sm`, `md`, `lg`, `xl`).

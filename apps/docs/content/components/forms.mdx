## Autocomplete

A search box that suggests options as the user types. Your `search` function does the fetching; the kit calls it once typing pauses (`debounceMs`, 300 by default), ignores answers that arrive out of order, and never shows a failed search's own error text. Arrow keys and Enter choose an option, Escape closes the list, and clearing the field calls `onChange(null)`.

<Example name="forms/AutocompleteExample" />

## Form

`useForm` holds the values, field errors and submitting state; `Form`, `FormField` and `FormSubmit` render it. On submit every `validate` function runs: problems show under their fields and the first invalid field is focused, and `onSubmit` is not called. While `onSubmit` runs, the fields and the submit button are disabled. If it throws, the form shows the message `submitErrorMessage` returns (or a generic one), never the error's own text, and keeps what was typed.

`FormField` passes `field.inputProps` for text inputs; for other controls use `field.value`, `field.setValue` and the `id` / `aria-*` props.

## DateRangePicker

A start and an end date, typed or picked. An end before the start is refused with the reason shown and the app is not told. Values are always Gregorian `yyyy-MM-dd`; `calendar="ethiopic"` only changes what the user sees and types.

<Example name="forms/DateRangeExample" />

## NumberField and CurrencyField

Numbers typed in the user's locale. `CurrencyField` takes and gives whole minor units (santim for ETB) with a currency code, so no fraction ever reaches the app; `currencyFractionDigits("ETB")` tells you the scale.

<Example name="forms/NumberFields" />

## OtpInput

A one-time code in separate boxes: typing or pasting fills the next boxes, only digits are kept, and `onComplete` fires with the full code. The first box accepts the phone's code suggestion.

## FileDropzone

Drop or browse for files. A file of the wrong type or size is refused with the reason and not kept; a new file replaces the kept one unless `multiple` is set.

# Hooks

`@kifiya/hooks`: small state hooks shared by the components and flows.

```sh
pnpm add @kifiya/hooks
```

## useApiMutation

From `@kifiya/hooks/query`, a separate entry so apps without React Query never load it. Invalidates query keys on success and toasts the result.

<Callout type="warning">
  On failure it shows the message your `errorMessage` maps the error to, or your
  `errorFallback`. It never shows the error's own text, which can be a backend's
  internal message.
</Callout>

Needs `@tanstack/react-query` with a `QueryClientProvider`, and a mounted `<Toaster />` from `@kifiya/ui`.

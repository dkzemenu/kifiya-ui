# Kifiya UI

Shared design tokens and React components for Kifiya web apps, published as `@kifiya/*` packages to the GitLab package registry.

| Package          | What it is                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| `@kifiya/tokens` | Colours, surfaces, text, status, radii, shadows and fonts, in light and dark                     |
| `@kifiya/ui`     | Radix-based primitives and Kifiya composites: tables, drawers, dialogs, stat cards, detail views |
| `@kifiya/hooks`  | Debounced values, pagination and drawer state, a React Query mutation helper                     |
| `@kifiya/flows`  | Permission guard, app shell, sign-in and change-password forms, filterable list page             |

Every example on these pages is live: switch the site between light and dark with the theme switch, and each example follows. Use the **Code** tab to copy an example.

**Start here:** [Installation](/getting-started/installation), then [App setup](/getting-started/app-setup).

The [`kifiya-ui` command](/tooling) sets the kit up in an app, and an [MCP server](/tooling#mcp-server-for-coding-assistants) lets coding assistants look the kit up.
